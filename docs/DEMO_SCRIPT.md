# Three-minute demonstration

Use the sandbox seller flow for the final hackathon recording. Identify the simulated public demo as simulation if you show it separately.

1. **0:00–0:20 — Problem.** A client and freelancer disagree about whether a small website revision is complete. RevisionPay freezes a shared definition of done and connects the result to an authorized PayPal payment.
2. **0:20–0:50 — Agreement and approval.** Show the original Northstar page, the three agreed requirements, and the $180 revision fee. Show the buyer's exact consent and PayPal sandbox approval. Point out that authorization is not a completed charge.
3. **0:50–1:30 — Incomplete work.** Publish the first revision. It fixes the trial CTA but adds an annual commitment and termination fee. Show the actual GenLayer REVISE finding with its evidence references. The charged amount remains $0.
4. **1:30–2:15 — Corrected work.** Publish the corrected page and submit it. Show the real Studionet transaction reaching successful finality. Explain that the backend checks the current page again and captures the fixed authorization once. Use clearly marked time cuts for network waits.
5. **2:15–2:45 — Receipt.** Show PayPal's completed sandbox capture, the evidence artifact, agreement digest, and GenLayer transaction in the receipt. Briefly show buyer review and manual acceptance as explicit alternatives.
6. **2:45–2:55 — Boundaries.** This prototype checks one page's visible copy and links. Studionet is a development environment; the capture service is application-controlled. Point judges to the open-source repository and setup instructions.

Do not include account passwords, secrets, invitation tokens, buyer personal data, or the owner sign-in link in the video. Keep the video under three minutes and use original audio/visuals or material you have permission to use.
